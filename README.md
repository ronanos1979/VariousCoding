# VariousCoding

A collection of small coding projects and exercises.

## Projects

### RustRemoval

Java coding exercises aimed at shaking off the rust and keeping problem-solving skills sharp. Built with Gradle and tested with JUnit Jupiter.

**Exercises so far:**

| Exercise | Description |
|---|---|
| `firstDuplicate` | Given an array of integers, return the first value that appears more than once (−1 if all unique) |
| `secondLargest` | Given an array of integers, return the second largest distinct value (−1 if none exists) |

**Stack:** Java · Gradle · JUnit 6

## Structure

```
VariousCoding/
└── RustRemoval/        # Java coding exercises
    └── src/
        ├── main/java/com/ronanos/Main.java
        └── test/
```

## Running RustRemoval

```bash
cd RustRemoval
./gradlew run       # run main
./gradlew test      # run tests
```
